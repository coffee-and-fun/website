## The formatting toolbar

The toolbar sits above the editor pane. One click wraps your selection:

- **B**: bold, *I*: italic, **S**: strikethrough
- **Link**: wraps the selection and asks for the URL
- **Lists**: bulleted or numbered
- **Quote**: blockquote

You can hide the toolbar in **Settings → Writing tools** if you prefer a bare editor.

## Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| <kbd class="kbd kbd-sm">⌘</kbd> <kbd class="kbd kbd-sm">B</kbd> | Bold |
| <kbd class="kbd kbd-sm">⌘</kbd> <kbd class="kbd kbd-sm">I</kbd> | Italic |
| <kbd class="kbd kbd-sm">⌘</kbd> <kbd class="kbd kbd-sm">K</kbd> | Insert link |
| <kbd class="kbd kbd-sm">⌘</kbd> <kbd class="kbd kbd-sm">F</kbd> | Find & replace |
| <kbd class="kbd kbd-sm">⌘</kbd> <kbd class="kbd kbd-sm">S</kbd> | Save |
| <kbd class="kbd kbd-sm">⌘</kbd> <kbd class="kbd kbd-sm">/</kbd> | Markdown cheatsheet |

On Windows and Linux, use <kbd class="kbd kbd-sm">Ctrl</kbd> instead of <kbd class="kbd kbd-sm">⌘</kbd>.

## Find & replace

1. Press <kbd class="kbd kbd-sm">⌘</kbd> + <kbd class="kbd kbd-sm">F</kbd>.
2. Type your search. Matches are counted as you type, with an optional **match case** toggle.
3. Jump between matches with the arrows, then **replace one** or **replace all**.

## Lists that just work

- Press <kbd class="kbd kbd-sm">Enter</kbd> in a list and the next bullet or number continues automatically.
- Press <kbd class="kbd kbd-sm">Tab</kbd> to indent a list item, <kbd class="kbd kbd-sm">Shift</kbd> + <kbd class="kbd kbd-sm">Tab</kbd> to outdent.

## The outline panel

Long document? Open the **outline** from the header. Every heading becomes a link, so you can jump anywhere in one click.
