## Turn the grid on or off

The **grid overlay** is on by default. Toggle it under the preview.

With it on, the generator draws grid lines over the art and adds coordinate numbers along the top and down the left side. With it off you get the clean picture with no lines, which is what you want if you're just sharing the image rather than building it.

Both versions are included in whichever PNG you download, so switch the toggle before you save.

## Read the coordinates

Coordinates run along two edges: column numbers across the top, row numbers down the left. Every tenth line is drawn heavier than the rest, so you can count in tens instead of counting every square.

That's the whole trick to building a large piece without losing your place. Pick a corner in the world, decide that corner is `1,1`, and build in ten by ten chunks. When you lose track, you only ever have to re-count within the current block of ten.

> **Build from the bottom up.** Row 1 is the top of the image. If you're building a wall standing up, start at the bottom row and work upward so you're never placing blocks above your head from a scaffold.

## Use the numbered build guide

The **build guide PNG** is the version to actually build from. Every cell carries a number, and that number is a block type.

Numbering is by frequency. **`#1` is the block you need most of**, `#2` is the second most, and so on down the list. This is deliberate: the low numbers are the blocks worth stocking up on first, and the biggest areas of your build are the ones you can clear fastest.

The same numbers appear in the block list text file, so the guide and the shopping list always agree.

## Spotlight one block at a time

Click any block in the list to **spotlight** it. The guide redraws with that block highlighted and everything else dimmed.

This is the fastest way to build a large piece. Rather than working row by row and swapping blocks in your hotbar constantly, fill one block type across the whole build, then move to the next. Spotlight `#1`, place every `#1`, spotlight `#2`, and keep going.

Click the same block again to clear the spotlight.

When a block is spotlighted, the build guide you download is the spotlighted version, so you can save one guide per block type if that's how you'd rather work.

## Sort the block list

The list sorts two ways:

**By count**: most used first. This matches the numbering, and it's the default.

**By name**: alphabetical. Useful when you're hunting for one specific block and can't remember its number.

## Print it

There's no print button, but the build guide is a normal PNG. Download it and print it like any image.

At 96 or 128 blocks wide the numbers get small on a single sheet of A4. If you're printing, either drop to a 48 or 64 grid, or print the spotlighted guides one block at a time, which stay readable because you're only reading one number.
