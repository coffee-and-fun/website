# Stillkeys privacy policy

Effective date: September 10, 2026. Publisher: Coffee and Fun LLC.

Stillkeys does not collect, store, or transmit personal information. It has no accounts, analytics, advertising, tracking, third-party SDKs, or network requests.

During an active session, Stillkeys discards keyboard events and checks Escape key state to support its exit control. It does not read typed text, record keystrokes, retain input history, or share input with anyone. The session timer and duration choice remain in memory and are cleared when the app quits. The decorative keyboard does not track physical keys.

The Direct edition requests macOS Accessibility permission to suppress session keyboard events. The Mac App Store edition does not request that permission and only consumes events in its own foreground app. Access can be revoked in macOS System Settings. The app stops its event handling when the cleaning session ends.

Links to support, email, or Apple's cleaning guidance open in another app. Data you voluntarily provide through those external services is subject to their policies. macOS may manage its own diagnostics and crash reports according to your system settings; Stillkeys does not include a separate diagnostics collection service.

Questions: hello@coffeeandfun.com. App support: https://www.coffeeandfun.com/support/.

This app-specific copy is provided for publication if desired; the project does not publish a web page automatically.
